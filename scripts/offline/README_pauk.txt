УСТАНОВКА И ОБНОВЛЕНИЕ СИСТЕМЫ «ПАУК» РЯДОМ СО СТАРОЙ ВЕРСИЕЙ (БЕЗ ИНТЕРНЕТА)
=============================================================================

Этот пакет позволяет развернуть новую систему «Паук» на рабочем сервере БЕЗ интернета
в отдельной папке (/opt/pauk) и на отдельном HTTPS-порту (по умолчанию 8443),
СОХРАНЯЯ старую систему (/opt/lan_calendar на портах 80/443) полностью рабочей.

КАК УПАКОВАНЫ БРАУЗЕР И ВСЕ КОМПОНЕНТЫ
--------------------------------------
Сборщик `make_pauk_bundle.sh` на вашем ноутбуке (с интернетом и Docker) собирает
готовые Docker-образы со всеми зависимостями внутри и сохраняет их в один архив:
  1. pauk.tar.gz       — основное приложение «Паук» (Node.js 22 + все npm-пакеты +
                         iputils-ping + сервер + бот + шаблоны и статика).
  2. pauk-caddy.tar.gz — HTTPS-сервер Caddy 2 + утилита iproute2 (автоопределение IP
                         сервера и выпуск локального сертификата для порта 8443).
  3. pauk-robot.tar.gz — сервис робота Яндекс Карт и Форм (Python 3.12 + Playwright +
                         БРАУЗЕР CHROMIUM со всеми системными библиотеками и шрифтами
                         внутри `/ms-playwright`). Скачивание браузера на сервере НЕ нужно!
  4. Файлы проекта     — docker-compose.pauk.yml, Caddyfile.pauk, caddy-entrypoint.sh,
                         код robot/, скрипты install.sh и selftest_pauk.sh.

1. СБОРКА АРХИВА НА НОУТБУКЕ (ГДЕ ЕСТЬ ИНТЕРНЕТ И DOCKER)
---------------------------------------------------------
Полный комплект для первой установки (приложение + Caddy + браузер Chromium в одном архиве):
  bash scripts/offline/make_pauk_bundle.sh full

Облегчённый пакет для последующих быстрых обновлений кода (без повторной упаковки 500 МБ Chromium):
  bash scripts/offline/make_pauk_bundle.sh app

В папке `offline-out/` появится архив `pauk-full-<дата-время>.tar` (или `pauk-app-<дата-время>.tar`).

2. УСТАНОВКА НА РАБОЧЕМ СЕРВЕРЕ БЕЗ ИНТЕРНЕТА
---------------------------------------------
Скопируйте `.tar`-файл на сервер и выполните:
  rm -rf ~/pauk-bundle
  tar xf pauk-full-ДАТА-ВРЕМЯ.tar
  cd pauk-bundle
  sudo bash install.sh

Что сделает `install.sh` автоматически:
  • Проверит контрольные суммы всех файлов (`SHA256SUMS`).
  • Загрузит в Docker образы `pauk:latest`, `pauk-caddy:latest` и `pauk-robot:latest` (с браузером).
  • Создаст отдельную папку `/opt/pauk` (старую `/opt/lan_calendar` и её контейнеры не трогает!).
  • Безопасно скопирует живую базу данных `/opt/lan_calendar/data/calendar.db` (включая WAL-журнал),
    ключи шифрования (`.field_key`, `.secret_key`, `.bot_api_key`, `.robot_api_key`), вложения
    и `.env` из старой версии в `/opt/pauk`.
  • Перенесёт сессию авторизации браузера Яндекс из старого тома `docker_robot_profile` в новый.
  • Запустит изолированные контейнеры `pauk-app` (127.0.0.1:3010), `pauk-caddy` (HTTPS :8443)
    и `pauk-robot` и проведёт самопроверку.

Дополнительные опции `install.sh`:
  sudo bash install.sh --port 9443               # выбрать другой HTTPS-порт (по умолчанию 8443)
  sudo bash install.sh --copy-db                 # заново перекопировать свежую БД со старой системы
  sudo bash install.sh --with-bot                # включить также контейнер VK-бота (pauk-bot)
  sudo bash install.sh --target /opt/pauk --from /opt/lan_calendar

3. КАК ОТКРЫТЬ ОБЕ СИСТЕМЫ ОДНОВРЕМЕННО
---------------------------------------
  • Старая версия : https://<IP_СЕРВЕРА>/        (порты 80 и 443)
  • Новая «Паук»  : https://<IP_СЕРВЕРА>:8443/   (отдельный порт и отдельная cookie `pauk_access_token`)
  • Сертификат CA : https://<IP_СЕРВЕРА>:8443/ca.crt
