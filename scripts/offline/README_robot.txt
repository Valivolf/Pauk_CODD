РОБОТ ЯНДЕКС.КОНСТРУКТОРА КАРТ — УСТАНОВКА НА СЕРВЕР БЕЗ ИНТЕРНЕТА
===================================================================

1. Сборка на машине с интернетом:
     bash scripts/offline/make_bundle.sh robot
   Появится файл yandex-robot-<дата>.tar (образ с Chromium, возится 1 раз).

2. Установка на рабочем сервере (после обновления основного приложения):
     tar xf yandex-robot-*.tar
     cd yandex-robot
     sudo bash install.sh
